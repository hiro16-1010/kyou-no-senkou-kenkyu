# 配布の手順（持ち主向け）

キットを直してメンバーに配り直すときの手順です。

## 1. zipを作る

リポジトリの一番上で次を実行します。`dist/` に Claude版と Gemini版のzipができます（`dist/` はコミットしません）。

```
python scripts/build_zips.py
```

## 2. リリースを作る（ブラウザで行う）

1. リポジトリの「Releases」→「Draft a new release」を開く。
2. 「Choose a tag」に新しい版の名前（例：`kit-v5`）を入れ、「Create new tag」を選ぶ。
3. タイトルに版と日付を入れ、説明欄に下の「リリースの説明文」を、版に合わせて直して貼る。
4. `dist/` のzip 2つを添付欄にドラッグする。GitHubは添付ファイル名の日本語を消すので、各ファイルの「Change this file’s name」欄で `kyou-no-senkou-kenkyu_claude.zip` と `kyou-no-senkou-kenkyu_gemini.zip` に名前を変える（zipの中のファイル名は日本語のまま）。
5. 「Publish release」を押す。
6. `/releases/latest` を開き、zipが2つ並んでいることを確かめる。

## 3. ゼミのDiscordで知らせる

リリースのURL（`/releases/latest`）と、どちらのzipを使うかを書いて投稿します。不具合はスレッドかIssuesで受け付けます。

## リリースの説明文（kit-v4のときのもの）

「今日の先行研究」の配布キットです。使うAIに合わせて、下の「Assets」から片方のzipをダウンロードしてください。

- **kyou-no-senkou-kenkyu_claude.zip**：Claudeの有料プランを使っている人向け。展開して「はじめに.md」から始めます。
- **kyou-no-senkou-kenkyu_gemini.zip**：それ以外の人向け（ChatGPTを使っている人もこちら）。Googleアカウント、Gemini APIのキー、OpenAlexのAPIキー（どれも無料）が要ります。展開して、構築手順書をGeminiに渡します。

緑の「Code」ボタンの「Download ZIP」は、Windowsでファイル名が文字化けすることがあるので使わないでください。

### この版の内容
- Claude版（kit-v4）：毎朝5本（縦の深掘り2・横の広がり2・遠い分野1）。初期設定で既読論文のPDFを登録すると、AIが変数を読み取って関心テーマの候補を出します。設定した当日に1回目の推薦を作れます。
- Gemini版：毎朝3本。日本語論文を中心にし、英語論文はおおむね3日に1本です。

### まだ確かめていないこと
- Claude版のPDF登録（AIの読み取り）と、当日の推薦の作成
- Gemini版の構築手順書の通しでの構築

うまく動かないときは、このリポジトリの「Issues」か、ゼミのDiscordで知らせてください。
