# Claude Code での始め方（持ち主向け）

このフォルダを GitHub の非公開リポジトリにして、Claude Code で開発を続けるための手順です。

## 1. 置き場所を決める

zipを展開した `kyou-no-senkou-kenkyu` フォルダを、パソコンの分かりやすい場所に置きます。OneDrive の同期フォルダ（デスクトップなど）の中は、Git の管理ファイルと同期がぶつかることがあるので避けます。

- 例：`C:\Users\（ユーザー名）\dev\kyou-no-senkou-kenkyu`

## 2. Claude Code でフォルダを開く

Claude Code を起動し、このフォルダを開きます。中にある `CLAUDE.md` を、Claude Code が最初に読み込みます（このリポジトリの方針や、守ることが書いてあります）。

## 3. 最初の依頼（そのまま送れます）

```
このフォルダを Git で管理して、GitHub に非公開（private）のリポジトリ「kyou-no-senkou-kenkyu」を作って最初のコミットを送ってください。
- 先に CLAUDE.md と README.md を読んで、方針を確認してください。
- コミットの前に、個人の情報（ページのURL・slug、定期タスクのID、メールアドレス、氏名）が入っていないか検索して確かめてください。
- GitHub のログイン（gh auth login）が必要なら、手順を教えてください。
```

GitHub CLI（gh）が入っていない場合や、ログインしていない場合は、Claude Code が手順を案内します。

## 4. その後の進め方

- キットを直したいときは、Claude Code に「○○を直して」と頼みます。キットは、頼んだときだけ書き換える方針です。
- 配布用のzipを作るときは「配布用のzipを作って」と頼みます（`scripts/build_zips.py` を使います）。
- ゼミのメンバーに配るときは、GitHub のリポジトリに招待するか、作ったzipを渡します。

## 5. ここに入れないもの

持ち主自身のページと毎朝の推薦（定期タスク）は、claude.ai 上で動いています。ページのURL、定期タスクの指示文（持ち主専用版）は、このリポジトリに入れません。
