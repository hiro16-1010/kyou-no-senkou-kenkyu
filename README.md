# 今日の先行研究キット

卒業研究のテーマを決めるために、読む価値のありそうな組織行動論の先行研究を毎朝紹介してくれる、自分専用のページを作るためのキットです。ゼミのメンバーが、それぞれ自分の環境で立ち上げて使うことを想定しています。

## できること

- 初期設定で、これまで読んだ論文のPDFを登録すると、AIが論文中の変数とその関係を読み取って集計し、関心テーマの候補を出す
- 初期設定をした当日から、おすすめの論文を紹介する（翌朝からは毎朝自動）
- 毎朝、先行研究を数本、役割（縦の深掘り・横の広がり・遠い分野）に分けて紹介する
- 各論文の結論を、変数どうしの関係を示すパス図（四角と矢印）で表示する
- 「読んだ・興味あり／あとで読む／パス」の反応を付けると、次の日からの紹介に反映される
- 変数の集計と、変数名から論文を逆引きする機能
- 英語論文のPDFを手に入れるルート（JSTOR、無料公開版、Google Scholar、阪大OPAC）の表示

カードの結論は、AIが論文の要旨から読み取ったものです。レジュメや卒論に引用するときは、必ず原文で確かめてください。

## どれを使うか

| 使っているAI | 使うフォルダ | 必要なもの |
|---|---|---|
| Claude | `claude/` | Claudeのアカウント（毎朝の定期タスクを使うので、有料プランが前提）。ダウンロードしただけでは動かず、チャットで2回頼む手順がある |
| Gemini | `gemini/` | Googleアカウント、Gemini APIのキー、OpenAlexのAPIキー（どちらも無料で発行できる） |

- Claude版：`claude/はじめに.md` から始めます。ファイルを2つ添付して、決まった文を2回送るだけで立ち上がります。詳しい説明は `claude/立ち上げ手順.md` にあります。
- Gemini版：`gemini/gemini版_構築手順書.md` をGeminiに渡し、手順書に沿って一緒に作ります。Google スプレッドシートと Apps Script で動きます。

## フォルダの中身

```
claude/   Claude版：はじめに、ページ（index.html）、定期タスクの指示文、立ち上げ手順、使い方
gemini/   Gemini版：構築手順書、使い方
tools/    Windows用の補助ツール（任意）
docs/     開発の記録
scripts/  配布用zipを作るスクリプト
```

### tools/（任意）

Windowsのパソコンで、論文のPDFを `保存日_タイトル.pdf` の名前で整理するためのツールです。使う場合は、`tools/` の中身（`_tools` フォルダを含む）を、自分のゼミ用フォルダにそのままコピーします。

- `PDFの名前を整える.bat`：自分でダウンロードした論文PDFをこのファイルにドラッグ＆ドロップすると、名前を `保存日_タイトル.pdf` に変えます。ダブルクリックすると、同じフォルダの「名前を変える」フォルダの中のPDFを処理して「後で読む論文」へ移します。Python（Microsoft Store の Python 3.12 など）が必要です。
- `論文を保存.bat`：ページの「PDFを保存」ボタンで作った保存依頼を読み、PDFを「後で読む論文」に保存します。キット版のページにはまだ「PDFを保存」ボタンがないので、今は使えません。

## 注意

- 自分のページのURLは、他の人に共有しないでください。反応や既読論文は自分専用のデータです。
- 海賊版サイトのリンクは使いません。
