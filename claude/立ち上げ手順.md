# 「今日の先行研究」立ち上げ手順（Claude版）

卒業研究のテーマを決めるために、読む価値のありそうな先行研究を毎朝5本紹介してくれる、自分専用のページを作る手順です。自分のClaudeに2回頼むだけで立ち上がります。所要時間は10分ほどです。

## キットの中身

| ファイル | 使い道 |
|---|---|
| index.html | ページそのもの。Claudeに公開してもらう |
| 定期タスクの指示文.md | 毎朝、論文を選んでページに書き込む処理の指示文。Claudeの定期タスクにする |
| 使い方.md | ページの使い方（反応の付け方、タブの説明、PDFの入手方法） |
| 立ち上げ手順.md | このファイル |

## 用意するもの

- Claudeのアカウント。毎朝の定期タスクとartifactを使うので、有料プランが前提です。
- 毎朝の推薦は、自分のプランの使用量を毎日少し使います。

## 手順1：ページを公開する

1. claude.ai で新しいチャットを開き、`index.html` を添付します。
2. 次の文をそのまま送ります。

```
添付の index.html を、中身を変えずに artifact として公開してください。タイトルは「今日の先行研究」にしてください。
公開する前に、このページが使う機能として次の3つを宣言してください。
- db：rules は path "papers" と path "config" をどちらも write "admin" にする
- user
- sample（PDFから既読論文を読み取るのに使う）
公開したら、ページのURLと slug を教えてください。
```

3. 返ってきたページのURLを開き、ページが表示されることを確かめます。この時点では論文は1本もありません。

## 手順2：初期設定をする

1. ページの「関心テーマ・既読論文」タブを開きます。
2. 「初期設定」の欄に、関心テーマを1行に1つずつ入れます（例：リーダーシップ、ワークモチベーション）。
3. ゼミなどで読んだ論文があれば、タイトルを1行に1本ずつ貼り付けます。なくても始められます。
4. 「この内容で始める」を押します。
5. 読んだ論文のPDFが手元にあれば、同じタブの「PDFから既読論文を登録」でPDFを選びます（複数まとめて選べます）。
   - AIがタイトルと引用文献リストを読み取って表示します。1本あたり数十秒かかります。
   - 最初の1回は、ページがAIを使ってよいかの確認が出るので、許可します。
   - タイトルと引用文献が合っているかを確かめて、「登録する」を押します。
   - 登録した論文は、翌朝から、実際に引用している文献をたどる「縦の深掘り」の起点になります。

PDFのファイルそのものはページに保存されません。読み取りのために、PDFの文字（冒頭と引用文献の部分）がClaudeに送られます。画像だけのPDF（スキャンしたもの）は読み取れないので、タイトルを手で入力してください。

関心テーマを1つも登録しないうちは、毎朝の推薦は始まりません。テーマと既読論文は、あとからいつでも足したり外したりできます。

## 手順3：毎朝の定期タスクを作る

1. 手順1と同じチャットに `定期タスクの指示文.md` を添付します。
2. 次の文をそのまま送ります。

```
添付の「定期タスクの指示文.md」の {{SLUG}} を、さきほど公開した artifact の slug に置き換えてください。
置き換えた全文を指示文にして、定期タスクを作ってください。
- 名前：毎朝の論文推薦
- 時刻：毎朝6時50分ごろ（Asia/Tokyo）
- 毎回、新しいセッションで動かす
作ったら、承認の設定（実行のたびに承認を求めるか、自動で承認するか）を教えてください。
```

3. 実行のたびに承認を求める設定になった場合は、定期タスクの設定で「Automatically approve」（自動で承認）に切り替えます。切り替えないと、朝の実行が承認待ちで止まります。組織の設定で切り替えられないこともあります。

## 手順4：翌朝に確かめる

翌朝7時ごろにページを開き、「推薦」タブに論文（最大5本）が並んでいれば完成です。カードの結論が、論文ページの要旨と食い違っていないかも、最初の数日は自分の目で確かめてください。

載っていないときは、次を確かめます。
- 初期設定で関心テーマを登録したか
- Claudeの定期タスクの一覧で、前回の実行が失敗していないか、承認待ちで止まっていないか

## 注意

- ページは公開した人だけが見られる状態で始まります。反応や既読論文は自分専用のデータなので、ページのリンクを他の人に共有しないでください。共有された人は、自分の推薦ではなく、あなたのデータを見ることになります。
- カードの結論はAIが要旨から読み取ったものです。レジュメや卒論に引用するときは、必ず原文で確かめてください。
- PDFの入手ルートにある「阪大OPAC」は大阪大学の図書館用です。他の大学の人は、自分の大学の図書館で誌名かISSNを検索してください。
- キットが新しくなったときは、新しい `index.html` を添付して「この内容で、さきほどの artifact を同じ slug のまま更新して」と頼みます。データは消えません。定期タスクの指示文が新しくなったときは、「定期タスク『毎朝の論文推薦』の指示文を、添付の内容（slug は置き換えて）に更新して」と頼みます。
